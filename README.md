"# Ecomerce-streamlit-App" 


Assalamualaikum everyone.
Mera naam Muhammad Ali Solangi hai aur aaj main apna project **E-commerce Streamlit Dashboard** present karne ja raha hoon.

Ye project ek interactive web dashboard hai jo e-commerce business ka data analyze karta hai aur usko visually attractive form me display karta hai.

Is project ka main purpose business data ko simple aur understandable banana hai taake users easily sales, profit aur product performance ko analyze kar saken.

Ye dashboard Python programming language aur Streamlit framework use karke develop kiya gaya hai.

Data ko ecommerce.csv file se load kiya gaya hai aur phir us data ko process karke different charts aur KPIs ke through show kiya gaya hai.

Is project se mujhe:

* Data analysis
* Dashboard development
* Streamlit framework
* Interactive chart creation

jaise practical skills seekhne ka moka mila.

# Slide 6: Product Analysis Section


Product Analysis section user ko kisi bhi specific product ki detailed performance dekhne ki facility deta hai.

### Step-by-Step Process:

#### Step 1:

User dropdown menu se koi product select karta hai.

#### Step 2:

Dashboard selected product ka data filter karta hai.

#### Step 3:

Us product ki:

* Sales
* Profit
* Quantity

calculate ki jati hai.

#### Step 4:

Bar chart generate hota hai jo different cities me us product ki sales show karta hai.

Is feature ki help se business owner easily identify kar sakta hai ke kaunsa product best perform kar raha hai.

# Slide 7: City Insights


City Insights section city-wise sales analysis provide karta hai.

### Step-by-Step Working:
